# Padrões validados

Um arquivo por atividade. Cada padrão nasce das trilhas em `../demonstracoes/` (ou, enquanto não há trilhas, da evidência do acervo), é escrito pelo A3 e marcado `validado` ou `pendente` pelo A4 contra os parâmetros fixos do catálogo. Só padrões validados entram nas instruções dos agentes de produção, por regeneração do catálogo pelo A2. Cada padrão cita a trilha ou os arquivos de origem.
